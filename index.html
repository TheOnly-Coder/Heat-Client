Frequently asked questions

Everything you might want to know about Heat Client — what it is, how to install it, ban risk, compatibility, and where to get help.

01What is Heat Client?

Heat Client is a 1.8.9 Forge Ghost client built for maximum server compatibility. It's designed to feel like a premium cheat client — without the premium price tag.

02Which Minecraft version and loader does it require?

Currently Heat Client requires Minecraft 1.8.9 with Forge. A 1.8.9 jar-mod version is coming soon, as well as an experimental 1.21.4 build for anyone wanting to test Heat Client on modern Minecraft.

03Is Heat Client free? Will it ever be paid?

Yes — Heat Client is completely free and will never be paid. Donations are always welcome, but the client itself will stay free forever.

04How do I install it?

Just drop the jar into your mods/ folder and you're done — you can instantly start using some of Heat Client's best features. No extra setup, no config files, no external launchers.

05What's the in-game hotkey to open the GUI?

The default GUI hotkey is Right Ctrl. A custom keybind option is coming soon so you can rebind it to whatever you prefer.

06How many modules are there, and what categories?

The module count is always changing as Heat Client gets daily updates, but as of writing this it has 53 modules across six categories: Render, Player, Exploit, Combat, Movement and Utility.

07Which modules are the headline features?

The module the dev is most proud of is Auto Dupe — no other 1.8.9 client has it, and it works on servers every single time. Beyond that, the standout modules are Spoof Click (and Spoof Key) and Criticals — critical hits aren't even in 1.8.9, so Heat Client finds a way around that limitation to deliver them anyway.

08Does Heat Client have chat commands?

Yes. If you don't like using the GUI or keybinds, you can toggle any module from chat with the syntax ![module name] [optional setting]. For example, !fly toggles Flight, and !fly speed 2 adjusts its speed setting. The chat input also has autocomplete for module names.

09Will I get banned using Heat Client?

Prolonged usage of any client — ghost or not — can get you banned from certain servers. That said, native 1.8 servers have limited anticheat options, so on those you're looking at roughly an 80% no-ban guarantee.

ViaBackwards / ViaRewind modern servers are a different story: their plugins are more flexible and usually target old clients specifically, since old client code is well-known and easy to block. Expect to be flagged much faster on those.

10Can I use Heat Client on Hypixel?

Technically yes — but you shouldn't. You'll likely get banned after about 1 competitive game, or around 6 games if you're sneaky. Hypixel's anticheat is in a different league from typical anarchy servers; don't risk your account.

11Is Heat Client compatible with other clients and mods?

Yes — Heat Client is compatible with other clients and mods. The one exception is Essential Mod: it isn't officially compatible because most of the time it crashes your game, though it can occasionally be fine. If you want to use both, test on a singleplayer world first.

12Does Heat Client work on Windows, macOS and Linux?

Yes. Heat Client was developed on Linux, tested on Windows, and uses multiple techniques to locate the correct game calls on each OS — so you don't crash on platform-specific edge cases.

13Is Heat Client malware-free? How can I verify?

Yes, Heat Client is malware-free. The hard part is verifying that — there's no automated way to prove it yet, and the developer is still figuring that out. Users are welcome to decompile the mod to inspect it, with the only condition being that you don't reuse any of the code or take inspiration from it for your own projects.

14Is the source code open?

The source code is open but only visible on special occasions (such as milestone releases or community events). To know when source drops happen, join the HotWillNotElaborate's Mods Discord server: discord.gg/5SbGUwnxkt.

15How often is Heat Client updated?

Heat Client is updated daily — and so far it's been updated multiple times per day. To know when a new version drops, either join the Discord (discord.gg/5SbGUwnxkt) or just check this page regularly — the version badge at the top auto-updates whenever a new release goes live.

16Where do I report bugs or suggest features?

Use the GitHub Issues tab on the Heat Client repo. Please include your Heat Client version, Minecraft version, OS, and steps to reproduce the bug — that makes it much easier to fix quickly.

17Is there a Discord server for Heat Client?

Yes — the invite link is discord.gg/5SbGUwnxkt. It's not exclusively Heat Client though: by joining, you agree to seeing "unrelated" projects from the developer too. Treat it as a general modding community server with Heat Client as the flagship.

18What's the official Heat Client server, and how do I join?

The official server is Will Anarchy at willanarchy.exaroton.me. You can join on Minecraft versions 1.7 through 26.2 — it's almost pure vanilla, with the only plugins being Frame Dupe and Legacy Edition Dupe Revival. A great place to test Heat Client in a real anarchy environment.

19What's the difference between Heat Client and other 1.8.9 clients?

Two main differences. First, Heat Client hasn't been abandoned for over 4 years like most other 1.8.9 clients. Second, Heat Client is literally 7 clients in one — it uses source code from Hydrogen, SkidBounce, ProModule, SkilledClient and others to deliver premium anticheat-detection prevention and the best modules from each, all in a single download.

20Why should I pick Heat Client over Meteor Client?

Meteor doesn't support old versions and doesn't have built-in auto duping. For 1.8.9 specifically, Heat Client is the obvious answer — 50+ modules (small compared to Meteor's 150+, but big compared to other 1.8 clients) plus a built-in server browser.

That said, there's no real rivalry: the developer uses Meteor Client as their main cheat client for newer versions. They don't compete — Heat Client just keeps getting better at what it does.
